# Clipture Feedback

This repository is the public feedback tracker for [Clipture](https://clipture.talkape.net), a screenshot and clipboard utility for macOS.

Use **Issues** to report a problem or suggest an improvement. Before posting, please remove screenshots, clipboard contents, email addresses, license information, and other private data.

Clipture 的公开反馈入口。你可以通过 **Issues** 报告问题或提出建议。提交前请移除截图内容、剪贴板内容、邮箱、许可证等隐私信息。
