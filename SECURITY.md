# Security policy

Do not open a public Issue for a security vulnerability, private screenshot, clipboard content, license record, payment record, or personal information.

Please use the private support page:

- English: https://clipture.talkape.net/support
- 中文：https://clipture.talkape.net/zh/support

Include the Clipture version, macOS version, affected workflow, and a minimal reproduction. Remove unrelated private content from attachments.
