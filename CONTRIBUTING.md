# Contributing feedback

Clipture's source code is maintained in a private repository, so this repository does not accept source-code pull requests.

Useful contributions include:

- a minimal, repeatable sequence for a bug;
- the Clipture version, macOS version, Mac model, and chip architecture;
- a clear description of the expected and observed result;
- a focused workflow suggestion based on actual use.

Before uploading screenshots or logs, remove private content. Payment, privacy, license, and security matters belong in the private support channel described in [SECURITY.md](SECURITY.md).
