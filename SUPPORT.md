# Support

## Public feedback

Use GitHub Issues for reproducible product problems and concrete feature suggestions. Search existing Issues first and keep each Issue focused on one workflow.

- Bug report: https://github.com/tageecc/clipture/issues/new?template=bug_report.yml
- Feature request: https://github.com/tageecc/clipture/issues/new?template=feature_request.yml
- General discussion: https://github.com/tageecc/clipture/discussions

## Private support

Use https://clipture.talkape.net/support for payment, sponsorship restoration, license, privacy, or security matters.

Never post screenshots, clipboard contents, email addresses, license data, payment references, or sensitive logs in a public Issue.
