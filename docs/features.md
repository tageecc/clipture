# Feature reference / 功能说明

| Workflow | What Clipture does |
| --- | --- |
| Smart capture | Select a region or an application window from the same capture overlay. Hold Shift to select multiple windows. |
| Scrolling capture | Scrolls the chosen region, samples settled frames, matches overlap, and produces one long image. |
| Annotation | Adds shapes, arrows, lines, text, mosaic, and numbered callouts before export. |
| OCR | Uses the macOS Vision framework locally and lets you select recognized text inside the capture. |
| Pin | Keeps a capture above other windows; the mouse wheel changes its scale. |
| Clipboard history | Stores enabled text, image, and file-list formats locally and provides search and filters. |

Clipture does not require an account for these features. Screenshots, OCR results, and clipboard contents are not uploaded.

---

| 使用场景 | Clipture 的处理方式 |
| --- | --- |
| 智能截图 | 在同一个截图浮层中选择区域或应用窗口；按住 Shift 可以选择多个窗口。 |
| 滚动截图 | 自动滚动选区、等待画面稳定、匹配重叠区域并生成一张长图。 |
| 标注 | 导出前添加图形、箭头、直线、文字、马赛克和步骤说明。 |
| 文字识别 | 使用 macOS Vision 在本机识别，并可以直接选择截图中的文字。 |
| 置顶 | 把截图保持在其他窗口上方，滚轮可以调整比例。 |
| 剪贴板历史 | 在本机保存已启用的文本、图片和文件列表格式，并提供搜索和过滤。 |
